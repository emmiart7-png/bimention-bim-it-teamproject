반응형외피 검토 도구 v0.1 시제품

사이트와 입면을 넣으면 루버를 자동으로 입혀 에너지 · 탄소 · 물량 · 공사비를 계산합니다. 숫자는 임시 단가 기준의 개략 검토입니다.

0. 지도에서 건물 고르기 (브이월드)

주소나 건물 이름으로 찾거나, 지도에서 건물을 클릭하세요.

1. 사이트

지도에서 건물을 고르면 위도 · 경도 · 주소가 자동으로 채워집니다.

2. 입면

이름방위°폭 m높이 m창면적비창 ㎡루버

방위: 입면이 바라보는 방향 (북 0 · 동 90 · 남 180 · 서 270). 창 ㎡를 비우면 폭 × 높이 × 창면적비로 계산합니다.

3. 루버 사양 · 가정값

기본값은 엑셀 1_입력값 · 2_단가조사 · 13_탄소·계절효과와 같습니다.

4. 일사량 출처

검토 대상

루버 시뮬레이션 (Unity)

Unity WebGL 빌드가 들어갈 자리입니다.
빌드를 unity/Build 폴더에 넣으면 여기에 뜨고, 건물 · 하루 재생 시각이 Unity로 전달됩니다.

결과

왼쪽에서 계산하기를 누르세요.

대안 비교

하루 재생 · 입면별 루버 평면도 (외부 반응형)

루버 날햇빛 방향위 = 바깥, 아래 = 실내, 점선 = 유리

누적 순이익 · 민감도 (통유리 대비)

선이 0 위로 올라가는 해가 손익분기입니다. 슬라이더는 왼쪽 가정값과 연결되어 있습니다.

연간 운영 히트맵 (외부 반응형)

닫힘 (진할수록 많이 돎)열림 · 햇빛 들어옴겨울 모드해 없음 · 입면 뒤

각 달 15일 기준, 30분 간격. 가로 = 시각, 세로 = 월.

입면별 (선택한 일사량 기준)

간이식 또는 Unity 결과일 때 표시됩니다.
