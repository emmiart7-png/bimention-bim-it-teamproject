반응형외피 검토 도구 v0.1 시제품

사용법

건물과 입면을 넣으면 루버를 자동으로 입혀 에너지 · 탄소 · 물량 · 공사비를 계산합니다. 처음에는 네이버 1784가 들어가 있어 바로 시뮬레이션할 수 있습니다.

다른 건물을 검토하려면

  1. 1. 지도에서 건물 고르기: 주소를 검색하거나 지도에서 건물을 누른 뒤 "이 건물로 입면 만들기"를 누릅니다.
  2. 2. 루버 달 입면 고르기: 오른쪽 평면도에서 입면 이름을 누르면 루버를 달거나 뗍니다.

루버가 움직이는 모습은 오른쪽 루버 시뮬레이션 / 평면도에서 날짜와 시각을 바꿔 가며 확인할 수 있습니다. 숫자는 임시 단가 기준의 개략 검토입니다.

1. 지도에서 건물 고르기

주소나 건물 이름으로 찾거나, 지도에서 건물을 클릭하세요.

1. 사이트

지도에서 건물을 고르면 위도 · 경도 · 주소가 자동으로 채워집니다.

2. 입면

입면을 누르면 루버를 달거나 뗍니다 (파랑 = 루버 있음)

검증용 계산

간이식: 어느 위치 · 방위나 직접 계산 (맑은 날 직달, 그림자 · 날씨 없음). 엑셀 검증: 엑셀 13 · 14번 시트와 같은 숫자인지 확인.

검토 대상

루버 시뮬레이션 / 평면도

루버 날 (날 0° = 유리에 수직)해 위치
Unity WebGL 빌드가 들어갈 자리입니다.
빌드를 unity/Build 폴더에 넣으면 여기에 뜨고, 건물 · 하루 재생 시각이 Unity로 전달됩니다.

외곽선 · 층수 · 층고값으로 만든 단순 모형입니다. 마우스 끌어서 돌리기, 휠로 확대 · 축소 가능합니다.

보고서용 화면 캡처

지금 시뮬레이션 화면(네이버 1784 = Unity, 선택한 건물 = 웹 3D)으로 찍습니다.
