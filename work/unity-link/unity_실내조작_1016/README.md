# 실내 카메라 조작을 외관과 같게 (2026-10-16)

지금 웹에서 Unity 화면을 돌릴 때

- 외관: 마우스 **왼쪽** 끌기 (LouverViewSetup.cs)
- 실내: 마우스 **오른쪽** 끌기 (다른 카메라 스크립트) → 휴대폰에는 오른쪽 버튼이 없어서 **실내가 안 움직임**

이 파일을 넣으면 실내도 외관과 같은 방식으로 움직여요.

| | 마우스 | 휴대폰 · 태블릿 |
|---|---|---|
| 둘러보기 | 왼쪽 끌기 | 한 손가락 끌기 |
| 확대 · 축소 | 휠 | 두 손가락 벌리기 · 오므리기 |

나란히 화면에서는 실내 화면(오른쪽 반) 안에서 할 때만 실내가 움직여요.

## 넣는 방법

1. **`Scripts/LouverInteriorLook.cs`** — 새 파일이에요. `LouverBridge.cs` 와 같은 폴더에 넣어요.
   씬에 붙일 필요 없어요 (열리면 스스로 생겨요). 실내 카메라는 `LouverBridge.interiorCamera` 를 써요.
2. **실내를 오른쪽 끌기로 돌리던 스크립트가 있으면 꺼 주세요** (실내 카메라에 붙은 카메라 조작 스크립트).
   둘 다 켜져 있으면 서로 카메라 방향을 덮어써서 튈 수 있어요.
3. (권장) **나란히일 때 외관도 왼쪽 반에서만 돌게:** `LouverViewSetup.cs` 의 `LateUpdate` 에서
   `if (m.leftButton.isPressed)` 를
   `if (m.leftButton.isPressed && exteriorCamera.pixelRect.Contains(m.position.ReadValue()))` 로 바꿔요.
   (안 바꾸면 나란히에서 실내 쪽을 끌 때 외관도 같이 돌아요.)
4. 전처럼 WebGL 빌드 (`louver`, Compression Disabled) → Releases 에 올려 주세요.

Unity 6000.6.4f1 에서 컴파일 오류 없는 것을 확인했어요.

## 확인 방법 (빌드 후)

- PC: 실내 화면을 마우스 왼쪽으로 끌면 둘러보기, 휠로 확대 · 축소
- 휴대폰: 실내 화면을 한 손가락으로 끌면 둘러보기, 두 손가락으로 확대 · 축소
- 나란히: 오른쪽(실내)을 끌면 실내만, 왼쪽(외관)을 끌면 외관만 움직임
